# Personal Wishlist Website

I’m the kind of person who constantly stumbles upon things I want to buy, and I never had a simple place to save them. Most apps felt too bloated or commercial, and spreadsheets were... not it.

So I built my own wishlist site!

It’s lightweight, minimal, and does exactly what I need: I can save an item’s name, how much it costs, and an image to remind me why I liked it in the first place. I also added a dark mode toggle because I tend to browse at night and my eyes thank me for it :)

This was a fun project to design and build from scratch, and it’s something I actually use all the time!

🔗 **Live Site**: [https://personal-wishlist.onrender.com/](https://personal-wishlist.onrender.com/)
